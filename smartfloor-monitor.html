Historical data is generated from the same simulation model used for the live monitor, parameterised to show a realistic improving OEE trend over 14 days. In a live deployment this view would read from the database populated by the edge collector.
Predictions are computed from the embedded historical dataset (laser_shifts.csv) and the live shift state. No ML library is used: methods are linear regression, exponential smoothing, threshold rules and Monte Carlo, all computed in-browser from the data.

Prediction methods: OEE forecast uses exponential smoothing of today’s running average against a 14-day historical mean. On-time confidence uses Monte Carlo simulation (2000 runs) sampling historical availability distributions. Maintenance prediction uses a rolling mean of days between lens-change events. Scenario planner recalculates OEE using the historical mean downtime profile adjusted by a 50% reduction in the top cause.
Both datasets below are generated by the same JavaScript simulation engine that drives the live monitor. They represent what a real deployment would capture: a per-shift summary table (one row per shift from the laser controller and operator inputs) and a per-event log (one row per sheet completed or stoppage logged). In production, the edge collector at the machine would write these rows to a database in real time. The dashboard would then read from that database rather than the embedded strings below.
